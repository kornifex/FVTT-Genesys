## Agent skills

### Issue tracker

Issues live in GitHub Issues on kornifex/FVTT-Genesys; use the `gh` CLI with `-R kornifex/FVTT-Genesys`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), as GitHub labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Code style

Before writing code, a commit or a pull request, read `docs/agents/code-style.md`.

### Releases

Before changing the version, the changelog or the release workflow, read `docs/agents/releasing.md`.
